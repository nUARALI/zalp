# «Залп» — браузерный «Морской бой» с тренером

## 1. Что это

«Залп» — браузерная игра «Морской бой» для конкурса Narxoz Incubator: игрок расставляет флот и сражается с компьютером трёх уровней сложности. Есть аккаунты (email + пароль), история партий в облаке и разбор каждой партии — режим «Тренер» с тепловой картой выстрелов, метриками и советами.

- Рабочая версия: https://zalp-weld.vercel.app/
- Репозиторий: https://github.com/nUARALI/zalp

## 2. Для кого и чем отличается

Для тех, кто хочет не просто играть, а становиться сильнее. После каждой партии «Тренер» показывает:

- тепловую карту ваших выстрелов (поле противника с номерами ходов);
- метрики: точность, потопления, серия попаданий, лишние выстрелы при добивании, доля «шахматной» охоты;
- ключевые моменты, где карта вероятностей предлагала клетку лучше выбранной;
- 3–4 совета на русском и список упущенных добиваний.

Идея монетизации (гипотеза, не реализована): в Pro-версии — расширенная статистика по времени, сравнение партий между собой и персональный план тренировок. **Платежи в проекте не реализованы**, платного функционала нет.

## 3. Как играть

- Поле 10×10, флот: 1×4, 2×3, 3×2, 4×1.
- Корабли не касаются друг друга, даже по диагонали.
- Попал — ходишь снова.
- После потопления клетки вокруг корабля отмечаются промахами автоматически.
- Повторный выстрел в клетку запрещён.

Ход игры: меню → расстановка флота → бой (ваше поле и поле противника) → результат со статистикой и разбором.

## 4. Возможности

- Расстановка вручную (тап по клетке, кнопка «Повернуть», тап по своему кораблю убирает его) и «Расставить случайно», «Сбросить». Кнопка «В бой» активна только при полном флоте.
- Три сложности ИИ:
  - **Лёгкая** — случайная непристрелянная клетка (`src/game/ai/easy.ts`);
  - **Средняя** — охота по шахматной сетке + добивание: соседи одиночного попадания, по двум попаданиям определяет ориентацию и идёт вдоль линии (`src/game/ai/medium.ts`);
  - **Сложная** — то же добивание, а охота по карте плотностей: подсчёт, сколько размещений оставшихся кораблей проходит через клетку, с учётом промахов и запрета касания (`src/game/ai/hard.ts`).
- Сохранение текущей партии в LocalStorage после каждого хода, продолжение после перезагрузки.
- Гостевой режим без входа; регистрация/вход/выход по email + пароль.
- История последних 20 партий, победы/поражения, процент побед, средняя точность, разбивка по сложностям (экран «Профиль»).
- Разбор партии «Тренером» на экране результата и по клику на партию в профиле.
- Адаптивная вёрстка под телефон (поля 10×10 умещаются на ширине 375px без горизонтального скролла), тёмная морская тема, интерфейс на русском.

## 6. Архитектура

- Игровая логика — чистый TypeScript в `src/game/` (движок, ИИ, тренер), без React и DOM; React-компоненты только отображают состояние и вызывают чистые функции.
- ИИ честный: получает только историю своих выстрелов и результаты (`AIKnowledge`), расположение кораблей игрока ему недоступно.
- Состояние игры — JSON-сериализуемый объект, хранится в LocalStorage и подходит для БД.
- Supabase: email-авторизация, таблица `games`, RLS-политики — каждый пользователь читает и добавляет только свои строки (`supabase/schema.sql`).

Ключевые папки:

```
src/
  game/          движок (engine.ts, types.ts, rng.ts)
  game/ai/       ИИ: easy.ts, medium.ts, hard.ts, common.ts, types.ts
  game/coach/    тренер: analyze.ts, types.ts
  components/    BoardView, AuthPanel, AppHeader, CoachPanel
  screens/       Menu, Placement, Battle, Result, Profile
  lib/           supabase-клиент, useAuth, games (сейв), profileStats, errors
supabase/
  schema.sql     таблица games + RLS
```

## 9. Запуск локально

```bash
npm install
# скопируйте .env.example в .env и вставьте значения:
# VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
# (Supabase Dashboard → Project Settings → API)
npm run dev    # http://localhost:5173/
npm test       # тесты Vitest
npm run build  # продакшн-сборка
```

SQL схемы выполните один раз в Supabase Dashboard → SQL Editor: содержимое `supabase/schema.sql`. Без `.env` игра работает гостем (облако отключено).

## 10. Известные ограничения (честно, по коду)

- Только игра против компьютера — мультиплеера нет.
- Реальных платежей нет (Pro — лишь гипотеза).
- Облачное сохранение требует входа и сети: без сети партия остаётся только в LocalStorage и показывается уведомление.
- В профиле видны только последние 20 партий.
- Для разбора партии из истории нужны сохранённые shots и флоты; если их нет — показывается сообщение вместо разбора.
- Сохранение в облако происходит один раз по завершении партии (upsert по id партии).
