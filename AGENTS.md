# Проект «Залп» — Морской бой для Narxoz Incubator

Веб-игра «Морской бой» для конкурса Narxoz Incubator. Рабочее название: «Залп».

## Стек

- Vite + React + TypeScript + Tailwind
- Vitest для тестов
- Позже: Supabase (auth + БД)
- Деплой: Vercel

## Правила игры

- Поле 10x10
- Флот: 1x4 (линкор), 2x3 (крейсера), 3x2 (эсминцы), 4x1 (торпедные катера)
- Корабли не касаются друг друга (даже по диагонали)
- Попал — ходишь снова
- После потопления соседние клетки автоматически помечаются как промахи
- Повторный выстрел в клетку запрещён

## Архитектурные требования (обязательные)

1. **Вся игровая логика в `src/game/` на чистом TypeScript, без React и без DOM.**
   Состояние — простой JSON-сериализуемый объект (без классов), чтобы его можно было хранить в LocalStorage и БД (Supabase).
2. **Честный ИИ:** компьютерный соперник получает только то, что игрок мог бы видеть (историю своих выстрелов и результаты), и никогда не читает расположение кораблей игрока напрямую.
3. **Логика покрыта тестами Vitest.**
4. **UI на русском языке, mobile-first, тёмная морская тема.**
5. **Никаких лишних зависимостей без необходимости.** Все заимствованные библиотеки записывать в `README.md` в раздел «Использованные технологии».

## Рабочие соглашения

- Не добавлять зависимости без обсуждения.
- Не смешивать UI и логику: React-компоненты только отображают состояние из `src/game/` и вызывают чистые функции.
- Все изменения логики сопровождать/обновлять тестами.
